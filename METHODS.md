# Reproducible synthetic protocol

## Virtual profiles

Twenty CP-inspired and seven typically developing-inspired profiles are generated with fixed random seeds. Profile type changes the distributions of coactivation, fatigue-like scaling, and transient activation bursts. These profiles are computational cases, not participants.

Published pediatric upper-limb studies should be cited only as motivation for physiological ranges and qualitative variability; their individual-level recordings are not copied or redistributed.

## Signals

Four synthetic EMG-like channels are generated at 1000 Hz: biceps, triceps, anterior deltoid, and posterior deltoid. A separate FDS-like grasp-effort proxy is computed from task phase and load. Kinematic reference signals are generated at 100 Hz from minimum-jerk reaching profiles.

## Preprocessing

Signals are segmented into 200 ms windows with 50% overlap. RMS features are computed per channel. Profile assignment precedes window extraction, ensuring that windows from one virtual profile cannot cross data subsets.

## Learning modules

The executable reference package uses a classical RBF SVM for the three-class intention task and RBF SVR models for angle prediction. The repository does not label the classical kernel result as a QSVM result. A genuine QSVM comparison requires the exact Qiskit feature map, version, backend, and stored predictions.

## Controller evaluation

The included controller results are generated by a lightweight numerical surrogate over 20 fixed perturbation seeds. They quantify numerical variability only. The OpenSim adapter intentionally requires a separately validated `.osim` model and OpenSim Python bindings.
